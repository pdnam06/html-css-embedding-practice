# Nhúng CSS vào trang HTML

Mỗi phần có đúng một tiêu đề h1 và một đoạn văn p với cùng nội dung, sử dụng một cách nhúng CSS riêng biệt.

| Phần | Tệp | Cách nhúng | Màu tiêu đề | Màu đoạn văn |
| --- | --- | --- | --- | --- |
| 1 | inline.html | Thuộc tính style trên thẻ | blue | red |
| 2 | internal.html | Thẻ style trong head | green | purple |
| 3 | external.html + style.css | Thẻ link nạp tệp CSS riêng | darkorange | teal |

Mở index.html bằng trình duyệt để chọn phần, hoặc mở trực tiếp từng tệp HTML. Không cần cài thư viện hay kết nối Internet.

Các trang ví dụ chỉ dùng CSS để đổi màu chữ theo yêu cầu, giúp dễ nhận biết vị trí khai báo của từng cách nhúng.
